# 当前能力与后续方向

Ordloom 1.0.0 提供模型管理、可视化页面、数据集与报表、权限与协作、通知与集成、离线与运维。详见 [完整发布说明](../releases/1.0.0.md)。

## 后续方向

源码已新增运维预检与任务主动告警、答卷后台导出与数据库投影检索，并修正后台 `supportsPush` 声明；这些能力尚未发布，见 [P1 指南](../guides/operations-and-submission-exports.md)。

- 更多行业数据配方与字段适配。
- 问卷条件显示与跳题、公开授权页面范围内的变更通知。
- 按实际部署完善运维诊断和使用体验。

实际任务调度、组织与权限适配、索引与容量、真机及外部群机器人等按目标环境验收。云函数和在线自定义代码执行不属于本版能力。
