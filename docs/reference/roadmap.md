# 当前能力与后续方向

Ordloom 1.0.2 继续完成公开通知故障恢复、统一组件读取调度和手动发布门禁；1.0.1 的运维、答卷、条件问卷、行业模板与 AntV 报表能力继续保留。详见 [1.0.2 发布说明](../releases/1.0.2.md)。

## 已完成批次

- 1.0.2 P1：临时故障自动续票和鉴权恢复、配置变化重新加载、最多 3 路读取和额度协调、手动发布质量门禁及双实例持续运行工具。部署和验证范围见 [稳定性指南](../guides/resilience-and-release-gates.md)。
- P1：运行预检、任务主动告警和恢复、答卷后台导出与数据库投影检索、`supportsPush` 声明修正。见 [运维指南](../guides/operations-and-submission-exports.md)。
- P2：条件显示、向后跳题、历史答卷语义；按页面授权的公开失效通知、一次性票据、同源和共享缓存保护。
- P3：库存、项目工时、线索三套新业务模板，共 17 套页面模板；JSON 标量、单值关联、时长模板适配；7 类 AntV 报表，共 20 种展示。见 [功能指南](../guides/conditional-pages-and-antv-reports.md)。

## 下一步

下一轮优先级按现有缺口排列，区别于已经随 1.0.1 交付的 P2/P3 批次：

| 顺序 | 建议开发项 | 当前边界 |
| --- | --- | --- |
| P2-1 | 页面草稿、公开发布版本与回滚 | 页面仍保存单份内容，公开访问反映最近保存；数据集的不可变版本已经实现 |
| P2-2 | 多序列图表与组件参数联动 | 基础图表仍为单值映射，尚无跨组件点击筛选或钻取协议 |
| P2-3 | 数值/日期条件与分步问卷 | 已有等于、包含、填写状态、显示条件和向后跳题，尚无类型化范围与章节进度 |
| P2-4 | 任务告警外发与运行指标 | 任务失败/恢复目前发站内通知，机器人目标未接入任务告警流程 |
| P3 | 派生指标、多值关联或第三方输入源 | 按具体业务另行定义权限、精度、去重、查询预算和凭据管理 |

同时验证宿主共享缓存、ASGI 代理、任务调度、组织与数据权限、索引及目标数据量。多值关联当前不直接开放；原始 JSON、文件与任意路径不自动变成查询能力。

目标大屏长期轮播、重连、扫码安装、HTTPS、外部群机器人和真机需在实际环境验收。云函数与在线自定义代码执行继续仅调研，不属于本版能力。
