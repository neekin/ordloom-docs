# 富文本编辑器

`RichTextField` 保存 HTML 字符串，适合文章、公告、商品说明等内容。

```python
from ordloom.editor.fields import RichTextField

body = RichTextField("正文", blank=True)
```

## 编辑能力

- 正文、标题、引用、代码块；加粗、斜体、下划线、删除线。
- 前景色、背景高亮、列表和四种对齐。
- 链接插入、编辑和移除。
- 图片上传、图片地址、替代文字、宽度编辑。
- 普通表格的插入与行列操作；全屏、HTML 源码和最多 100 条独立历史记录。

源码修改实时同步 Form，不必返回可视模式再保存。表单重置、外部回填、多个编辑器和不同记录保持各自状态。

## 常用配置

```python
ordloom_fields = {
    "body": {
        "rows": 12,
        "placeholder": "从这里开始编写正文…",
        "max_upload_size_mb": 5,
    }
}
```

工具栏、粘贴与拖入图片使用同一上传流程。默认图片上限 10 MB，服务端还会检查实际图片内容、字段、记录及明细权限。

上传期间可以继续编辑。切换记录、重置、进入只读或使插入位置失效时，旧上传结果不会写进新草稿；表单保存会等待当前上传任务。

## 键盘与表格

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd+B`、`I`、`U` | 常用文字格式 |
| `Ctrl/Cmd+K` | 编辑链接，优先于工作台页面搜索 |
| `Ctrl/Cmd+Z` | 撤销 |
| `Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` | 重做 |
| `Tab` / `Shift+Tab` | 移动普通表格中的单元格 |
| `Escape` | 关闭设置面板并返回正文 |

普通表格最多 20 行 × 10 列，末尾 Tab 可新增一行。粘贴的合并单元格会保留；这类结构通过源码调整，避免自动增删破坏合并关系。

## 内容与只读

前端统一清理回填、粘贴、拖入和源码 HTML，保留常见排版，移除脚本、事件、危险链接及不支持的嵌入内容。其他业务入口接收 HTML 时，仍应采用自己的服务端内容策略。

纯空标签按空值参与必填校验。只读或禁用时不再接受编辑，中文输入法确认键不会误触发外层表单。
