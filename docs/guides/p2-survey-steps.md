# 类型化条件、章节与分步问卷

本指南描述 Ordloom 1.1.0 的类型化条件和分步问卷能力。

问卷继续使用原来的公开页面、分享保护、答卷权限与同步/后台导出入口。无章节、无新条件或未开启分步的既有问卷保持连续填写。章节与条件保存在题目配置中，每份答卷保留当时的题目快照；修改页面不会改写历史题目、条件或答案。

## 编辑与填写

在表单组件的题目编辑器填写“新章节标题”，该题开始一个新章节，后续留空题目延续此章节。每个标题最多 100 字。没有标题的首段默认称为“开始”；即便章节首题被条件隐藏，后续可见题目仍属于该章节。全部题目不可见的章节自动跳过。

站内表单的“填写方式”可选“连续填写”或“按章节分步”。分步模式提供上一步、下一步、当前步数和已填题数，可关闭填写进度显示。下一步校验当前章节，提交复核全部可见题目；服务端继续独立校验，不能绕过必填与条件。返回修改前题后，因条件或跳题而不可达的旧答案立即清除，隐藏必填题不阻止提交。预览只校验而不写答卷；公开页仍须开放收集。

外部地址表单保持原生 POST 和连续布局，分步仅适用于站内收集。

## 条件语义

每题仍支持 1–5 条 all/any 条件，只能引用前题；单选/下拉跳转仍只能指向后续题目或结束。

| 运算 | 支持题型 | 语义 |
| --- | --- | --- |
| `eq` / `ne` | 原来支持的题型 | 原值等于/不等于，保留旧文本比较语义；数字 `1.0` 与 `1` 仍不同 |
| `typed_eq` / `typed_ne` | 数字、评分、日期、时间、本地日期时间 | 数值或日期时间相等/不等，例如数字 `1.0` 与 `1e0` 相等 |
| `gt` / `gte` / `lt` / `lte` | 同上 | 大于/大于等于/小于/小于等于；日期时间为早晚顺序 |
| `between` | 同上 | 起止两个值组成数组，包含上下界；起始值不得大于结束值 |
| `includes` | 多选 | 包含指定选项 |
| `answered` / `empty` | 全部题型 | 填写状态，不携带比较值 |

数字以字符串保存和比较，不经过 JavaScript `Number` 或二进制浮点。比较值最多 100 字符，支持正负数、小数及科学计数法，指数绝对值不超过 10000；评分仍是 1–5 的整数。无效/空的数值或日期不会满足新类型化条件，包含“不等于”；提交时无效来源答案会收到校验错误。

日期使用严格公历 `YYYY-MM-DD`，校验闰年、实际月份天数与 1–9999 年。时间支持 `HH:mm[:ss[.ffffff]]`，本地日期时间支持 `YYYY-MM-DDTHH:mm[:ss[.ffffff]]`。不接受时区、`Z` 或偏移量；比较使用填写的本地日历时间，不自动换算时区。省略的秒或小数视为零，精度最高微秒。需要绝对时间的调查应在题目中明确要求使用哪个时区。

```json
{
  "submitMode": "internal",
  "accepting": true,
  "stepMode": "chapters",
  "showProgress": true,
  "schema": [
    {"id": "amount", "type": "number", "label": "申请金额", "required": true, "chapter": "申请信息"},
    {"id": "reason", "type": "textarea", "label": "大额说明", "required": true, "chapter": "补充说明", "showWhen": {"match": "all", "conditions": [{"field": "amount", "operator": "gte", "value": "9007199254740993.0000000000000001"}]}},
    {"id": "date", "type": "date", "label": "计划日期", "required": true, "chapter": "确认"}

```

## 答卷、导出与历史

分步信息是展示配置，最终仍一次提交，未增加分步自动存档或中途补交。提交只保留实际可达题目的答案；同步 CSV/XLSX、后台 CSV/XLSX 和汇总均使用答卷自身快照计算可见题目。章节不是业务答案，不生成额外导出行。数字答案保持原始精确字符串；统计原有容量和精度预算不变。

本批无需为问卷增加数据库迁移，也不增加新的授权或缓存隔离维度。公开页面若启用了页面发布版本，应先发布当前问卷配置；答卷以实际公开的配置校验。
