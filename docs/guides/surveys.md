# 表单与调查问卷

在大屏或 H5 中拖入表单组件，配置题目后选择站内收集或外部 POST 地址。编辑预览用于试填，站内实际提交发生在已保存的公开页面。

## 题目与校验

| 类型 | 内容 |
| --- | --- |
| `text` | 单行文本 |
| `textarea` | 多行文本 |
| `email` | 邮箱 |
| `tel` | 电话 |
| `number` | 数字 |
| `radio` | 单选 |
| `checkbox` | 多选 |
| `select` | 下拉选择 |
| `rating` | 评分 |
| `date` | 日期 |
| `time` | 时间 |
| `datetime` | 本地日期时间 |

支持 1–40 题，题目标识唯一且稳定，标签最多 200 字符。选择题使用 1–30 个非空且不重复的选项。
可以增删、排序题目并设置必填；服务端再次验证题目类型、格式、长度和答案范围。
日期、时间和本地日期时间不隐式换算时区，按题目语义保存。

## 条件与跳题

每题支持 1–5 条全部/任一显示条件，只引用前题；单选/下拉可跳至后题或结束。隐藏题不校验必填，浏览器清除原答案，服务端丢弃隐藏值。历史快照保留规则，详情、统计和导出只计入实际显示题目。配置步骤和例子见 [条件问卷指南](conditional-pages-and-antv-reports.md)。

1.1.0 增加数字、日期、时间的类型化条件、章节与分步进度，见 [分步问卷指南](p2-survey-steps.md)。旧条件与连续填写保持兼容，最终仍一次提交。

## 开放收集

1. 在组件中选择站内收集，开启「开放收集」。
2. 保存页面，核对分享开关、有效期、密码及链接令牌。1.1.0 若已启用页面版本管理，还需发布当前草稿，实际提交按当前公开版校验。
3. 通过公开链接试填并提交，检查回执。
4. 在资源管理入口查看收集结果。

提交保留 Django CSRF、分享状态和访问凭据检查，并有请求去重和提交频控。
关闭/过期分享或停止收集会阻止新提交；密码失败还受 [共享限速](sharing-and-task-diagnostics.md) 控制。
外部地址模式按题目稳定标识进行原生 POST，由目标服务负责处理。

## 答卷、导出与汇总

当前资源管理者可以按表单、时间和关键词筛选答卷，查看明细、CSV/Excel 导出与统计。
每份答卷保存当时的题目快照；改题不会改写已提交答案，汇总按题目版本分别统计。
选择题显示分布，评分和数字支持统计；数字使用精确 Decimal 规则，导出不把字符串公式当作可执行公式。

关键词与汇总受有界扫描预算限制，超过限额时缩小时间或表单范围。删除页面会连同该页答卷删除。
条件显示、向后跳题与提前结束、数据库投影检索和私有后台导出均自 1.0.1 起提供。规则配置见 [条件问卷指南](conditional-pages-and-antv-reports.md)，启用、迁移和权限边界见 [答卷后台导出指南](operations-and-submission-exports.md)。
