# 品牌、主题与导航

## 项目自己的品牌

在 Django 设置中定义工作空间名称、Logo 和首页标题：

```python
SIMPLEUI_SITE_TITLE = "研究协作平台"
SIMPLEUI_SITE_SUBTITLE = "课题 · 文档 · 研究进展"
SIMPLEUI_LOGO = "/static/brand/logo.svg"
SIMPLEUI_HOME_TITLE = "研究工作台"
SIMPLEUI_DEFAULT_THEME = "teal"
```

这些兼容配置键继续有效。未设置站点标题时使用 `admin.site.site_header`；项目名称与插件产品品牌分别管理。

`SIMPLEUI_LOGO` 可以是文字或图片路径。图片请放在项目的静态资源中，并跟随部署收集。

## 个人外观

从顶栏「外观与体验」调整：

| 项目 | 可选内容 |
| --- | --- |
| 主题 | 远山蓝、深海蓝、鸢尾紫、青瓷、松石绿、砂金、胭脂、月白 |
| 显示模式 | 浅色、深色、跟随系统 |
| 导航 | 浅色或深色侧栏 |
| 信息密度 | 舒适或紧凑 |
| 字号 | 12、14、16 |
| 圆角 | 4、10、16 |
| 内容宽度 | 流动或居中限制宽度 |
| 动效 | 开启或关闭，并尊重系统减少动态效果设置 |

个人偏好保存在当前浏览器，优先于项目默认主题。点击恢复默认可以重新采用项目初始外观。

## 页面导航

- 左侧菜单根据当前账号允许访问的模型生成。
- `Ctrl/Cmd+K` 打开搜索，可输入中文名称、应用分组或 `app.model`。
- 多页面标签保留各页状态；方向键、Home、End 可移动标签焦点，Delete 关闭当前业务标签。
- 页面管理菜单支持关闭其他页面或右侧页面。
- 模块直达地址使用 `/admin/#page=m:projects.project`；模型标识含特殊字符时应对参数编码。
- 窄屏自动切换抽屉导航，列表在自身容器中横向滚动。

## 主题色的使用

前端扩展可使用 `--su-bg`、`--su-surface`、`--su-text`、`--su-muted`、`--su-primary` 等变量。主题文字使用 `--su-primary`；带白字的实色底使用 `--su-primary-fill`。错误文案使用 `--su-error-text`。

主题与新品牌视觉探索不是同一件事。[附录中的概念图](../appendix/design.md)用于讨论未来布局，当前版本能力以实际组件为准。
