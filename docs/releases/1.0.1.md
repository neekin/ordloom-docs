# Ordloom 1.0.1 更新说明

1.0.1 发布 P1 运维与答卷增强，并完成 P2 和本批 P3。原有资源权限、固定发布版本、无规则问卷与旧报表继续兼容。

## 本版新增

- 运维预检、默认关闭的任务站内告警与恢复、共享缓存去重；答卷 CSV/Excel 后台私有导出、任务状态和数据库投影检索。
- 问卷 1–5 条 all/any 显示条件与向后跳题，隐藏题答案清除，必填、历史详情、汇总和导出按实际显示题目处理。
- 默认关闭的公开页授权通知：同源短期一次性票据、共享限速、防重放、授权撤销、心跳、重连与轮询兜底；只发组件失效信号，数据继续按既有权限与映射重读。
- 库存概览、项目工时、线索跟进三套业务模板，业务模板共 6 套、全部页面模板共 17 套。支持模板 JSON 标量、单值关联主键和 Duration 秒数汇总。
- 7 类 AntV 报表：桑基、矩形树、圆打包、层级树、关系网络、热力与环形条；报表共 20 种展示方式，支持嵌入、刷新、导出和显式离线快照。

## 安装

```bash
pip install --upgrade ordloom==1.0.1
# 可选数据层，Python 3.10+、Django 5.2+
pip install --upgrade 'ordloom[graphql]==1.0.1'
python manage.py migrate
python manage.py collectstatic --noinput
```

核心支持 Python 3.9+、Django 4.2+。P1 包含 0027 迁移，P2/P3 无新迁移。任务告警、后台答卷导出及公开通知须显式启用，由宿主配置共享缓存、ASGI 与调度。
