32 种字段组件 ​

字段通过元数据中的 type 选择前端控件。普通 Django 字段会自动识别，也可以用 ModelAdmin.ordloom_fields 调整外观。

类型用途 / 来源主要值形态
text文本、CharField字符串
email邮箱字符串
url链接字符串
textarea多行文本字符串
password业务凭据输入新值、空字符串保留、显式 null 清除
password_statusUserAdmin 密码状态状态对象，服务端生成
hidden隐藏表单字段字段原值
display只读信息字段值或显示内容
number整数、Decimal / 大整数数字或保留精度的字符串
select单项选择、外键选项标识
m2m多对多、多选标识数组

treeselect组织树单选节点标识
cascader层级路径/ 分隔路径
autocomplete候选输入字符串

radio单选组选项标识

segmented分段选择选项标识

password_status、display 等类型通常由服务端按实际表单生成，不必为它们再增加一个业务模型字段。组件类型也不等同于 Django 字段基类名称。

使用组件字段 ​

python
from django.db import models
from ordloom.components import fields
from ordloom.editor.fields import RichTextField, MDTextField

class Content(models.Model):
    title = models.CharField(max_length=80)
    priority = fields.SliderField(min_value=0, max_value=100, default=50)
    rating = fields.RateField(max_value=5, default=0)
    color = fields.ColorField(default="#4f62d9")
    body = RichTextField(blank=True)
    notes = MDTextField(blank=True)

评分、滑块等字段仍是原生数值存储。模型迁移、数据库约束和项目校验不会因为换了控件而消失。

常用外观参数 ​

配置含义
type内置或自定义组件类型
placeholder输入提示
rows文本或编辑器初始高度
span表单宽度，通常为 1 或 2
min / max / step / precision数值界面选项
accept / max_upload_size_mb上传格式与大小
titles / filterable穿梭选择标题及搜索
tile_url / tile_attribution地图底图配置

控件禁用只影响交互时，应同步考虑原生表单和服务端权限配置。
