配置参考 ​

开发源码提供可选 ORDLOOM_MEMBERS 注册开关、会话时长、共享缓存频控与宿主账号工厂，完整默认值见 CMS 与会员配置。默认不开放注册，CMS 站点另有公开开关。

ORDLOOM_SHOP 控制可选商城目录/下单开关、待确认截止时间和频控额度，见 商城配置。目录与下单均默认关闭，会员停用时商城连带停用。

ORDLOOM_WECHAT 控制可选微信接入、可信公开源站、服务端凭据引用、时间窗口与留存；默认关闭，凭据不通过后台输入/回传。见 微信配置与平台要求。

以下为 Ordloom 1.1.0 读取的配置名称，统一使用 ORDLOOM_*。

分享与后台任务 ​

设置默认 / 行为
ORDLOOM_SHARE_LIMITS默认开启；300 秒内同来源/资源 10 次、同来源跨资源 100 次失败预算
ORDLOOM_TASK_DIAGNOSTICS默认关闭；启用后超级管理员只读查看安全执行元数据与队列汇总

完整配置、共享缓存要求和保留边界见 分享密码与任务诊断。

1.0.1 的 ORDLOOM_TASK_ALERTS、ORDLOOM_SUBMISSION_EXPORTS 默认关闭；ORDLOOM_SUBMISSION_SEARCH_ROWS 默认 100000，详见 P1 运维与答卷指南。这些增强自 1.0.1 起提供。

数据、协作与集成开关 ​

以下能力按宿主需要启用；界面可见性不代替数据权限。

设置默认 / 内容指南
ORDLOOM_GRAPHQL默认关闭；字段白名单、查询预算与能力目录模型与权限
ORDLOOM_PUBLIC_EVENTS默认关闭；按页授权的同源短期票据、失效通知、心跳与限速公开通知
ORDLOOM_EVENTS默认关闭；失效通知、签名与订阅预算事件与服务
ORDLOOM_REPORT_EXPORTS默认关闭；导出调度、留存、文件和源记录预算报表与导出
ORDLOOM_COLLABORATION默认关闭；工作区、角色与逐资源授权协作
ORDLOOM_ORGANIZATIONS默认关闭；宿主组织、成员与稳定身份映射组织接入
ORDLOOM_DATA_SERVICES默认关闭；独立服务身份、只读字段和固定版本授权只读服务
ORDLOOM_WEBHOOKS默认关闭；批准目标、后台权限上下文与机器人Webhook
ORDLOOM_PWA离线程序和业务快照分别显式开启离线
ORDLOOM_SESSION_DEVICES默认关闭；会话设备、中间件及保留数量会话安全
ORDLOOM_SHARE_ANALYTICS默认关闭；分享入口访问记录及预算分享
ORDLOOM_AUDIT_RETENTION默认永久保留；可配置分批清理周期审计留存

使用手册中相应模块的完整字典示例配置；不要仅为了显示菜单开启缺少依赖或调度的能力。

1.1.0 新增配置 ​

以下增强从 Ordloom 1.1.0 提供：

设置默认 / 行为
ORDLOOM_TASK_ALERTS.external_targets空列表；最多 10 个批准的 bot:<标识>，不接受任意 URL
ORDLOOM_TASK_ALERTS.external_owner未配置；外发负责人必须是当前有效超级管理员
ORDLOOM_TASK_ALERTS.external_retry_seconds30（1–3600）秒；入队补偿指数退避，单次最多 3600 秒
ORDLOOM_TASK_ALERTS.external_max_attempts12（1–100）；每轮入队尝试上限，失败需显式重试
ORDLOOM_TASK_ALERTS.external_max_age_seconds86400（60–604800）秒；原事件补偿期限，手动重试不续期
ORDLOOM_RUNTIME_METRICS默认关闭；共享缓存分钟桶与安全汇总，缓存不可用不阻断原请求

完整例子、告警故障隔离、指标窗口和权限见 任务告警外发与运行指标。页面版本、图表联动和问卷分步不新增独立开关；页面版本需要 0028 迁移，其使用方式见 路线图。

入队补偿需要核心 0030 迁移；复用原 default 数据库和共享缓存。关闭、撤权或改变原目标配置后取消旧意图，显式失败重试不恢复取消事件。命令、状态与第三方验收协议见 P1 入队补偿与运行升级验收。

站点与工作空间 ​

设置默认 / 行为
ORDLOOM_SITE_TITLE未提供时取 admin.site.site_header
ORDLOOM_SITE_SUBTITLE管理工作空间
ORDLOOM_LOGO可配置文字或图片路径
ORDLOOM_DEFAULT_THEME首次进入及恢复默认时使用的主题
ORDLOOM_HOME_TITLE首页标签标题，默认「首页」
ORDLOOM_HOME_ICON首页图标，默认 fa fa-home
ORDLOOM_HOME_PAGE默认打开的模型管理地址
ORDLOOM_INDEX默认打开地址的兼容别名
ORDLOOM_HOME_INFO是否显示服务器信息，默认 True
ORDLOOM_ANALYSIS是否显示统计 / 图表，默认 True
ORDLOOM_ICON菜单图标开关，默认 True
ORDLOOM_LOADING初始加载提示开关，默认 True
ORDLOOM_CONFIG自定义菜单字典

主题 key：default、midnight、violet、teal、forest、amber、crimson、light。

自定义菜单 ​

python
ORDLOOM_CONFIG = {
    "system_keep": True,
    "menus": [
        {
            "name": "业务协作",
            "icon": "fa fa-folder",
            "models": [
                {"name": "项目", "url": "/admin/projects/project/"},
                {"name": "团队", "url": "/admin/projects/team/"},
            ],
        },
    ],
}

地址应对应实际注册模型。自定义菜单仍受权限限制，不会让无权模型自动变为可访问。

接管、上传与验证码 ​

设置默认
ORDLOOM_FULL_TAKEOVERTrue，接管挂载点下管理界面路径
ORDLOOM_MAX_UPLOAD_SIZE_MB50，服务端上传总上限
ORDLOOM_CAPTCHA_TIMEOUT180，验证码有效秒数

登录验证码是否启用由站点配置表保存，在有权限的账号菜单中修改；不是通过这里新增一个不存在的布尔设置。

字段与 Admin 扩展点 ​

  • ordloom_fields：主表或 inline 字段外观。
  • ordloom_soft_delete = False：关闭软删除自动识别。
  • get_trash_queryset(request)：自定义回收站数据范围。
  • soft_delete_model(request, obj) / restore_model(request, obj)：软删除、恢复逻辑。
  • get_log_queryset(request)：符合业务范围的日志查询。

原生 ModelAdmin、ModelForm 和 FormSet 钩子继续承担业务规则，详见表单与关联明细。

子应用 SDK 设置（1.1.0 起） ​

ORDLOOM_DISABLED_APPS 为停用的子应用 ID 列表，默认空列表。ORDLOOM_APP_TASK_CONTEXT 可设置可信的 factory(user, using) 导入路径，构造任务的宿主权限上下文。现有 ORDLOOM_TASK_DIAGNOSTICS 控制任务观测，缓存继续使用宿主 default cache。

子应用不自动引入租户边界、客户权限或远程代码执行。完整清单与配置见 子应用 SDK。

ORDLOOM_APP_RECIPES 扩展纯声明行业配方；与内置合计最多 32 项，只含 ID、标签、说明、必选/可选应用、步骤和边界，不接受执行代码或导入路径。示例见生态开放与配方。
