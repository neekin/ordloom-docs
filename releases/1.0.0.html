Ordloom 1.0.0 发布说明 ​

[1.0.0] - 2026-11-11 ​

Ordloom 1.0.0 提供 Django Admin 工作台、可视化页面搭建和基于现有模型权限的数据分析能力。 发行包、Python 模块和 Django 应用均为 ordloom；设置统一为 ORDLOOM_*，Admin/字段扩展点和管理命令统一为 ordloom_*。 应用迁移标签与权限前缀为 ordloom，应用表使用 ordloom_*。

安装与接入 ​

bash
pip install ordloom==1.0.0
# 可选 GraphQL 数据层：Python 3.10+、Django 5.2+
pip install 'ordloom[graphql]==1.0.0'

核心支持 Python 3.9+、Django 4.2+。注册 ordloom、挂载 ordloom.urls 后执行迁移与静态文件收集即可接入；普通安装无需 Node.js。 完整步骤见 接入文档 和 GitBook 使用手册。

工作台与模型管理 ​

  • React 19、Ant Design 6、8 套主题、明暗模式、品牌配置、多标签页、命令面板及移动布局。
  • 原生 Admin 模型搜索、筛选、排序、分页、行内编辑、批量操作、CSV 导出和回收站。
  • ModelForm/FormSet 校验、分组/分步表单、普通/通用关联明细和字段权限，复用宿主保存钩子与事务。
  • 32 类字段控件指南，包含富文本、Markdown、精确 JSON、业务凭据、图片/文件/视频、关联选择及地图取点。
  • 可拖拽工作台、5 套工作台模板、真实模型计数、操作趋势与按权限读取的日志。

可视化页面、大屏与问卷 ​

  • 数字大屏和 H5 画布，拖拽、缩放、对齐、图层、撤销重做、JSON 导入导出、图片素材、预览和全屏。
  • 39 种搭建选项、22 类组件，包含 11 类 ECharts 与 7 类 AntV 图；11 套静态模板、3 套业务数据模板。
  • H5 载入、进入视口及跟随滚动动画，支持位移、缩放、视差和逐行文字效果。
  • 多屏轮播，独立配置顺序、停留时间、循环、暂停、切屏、预取和失效页面跳过。
  • 12 类问卷题目、服务端校验、提交去重、频控、答卷快照、筛选、CSV/Excel 导出及题目版本汇总。
  • 页面和轮播的 UUID 分享、访问密码、有效期、独立链接令牌、二维码及可选访问统计。
  • 分享密码默认限速：每 300 秒同来源/资源最多 10 次失败，跨资源最多 100 次；429/Retry-After、同密码等待后重试，缓存异常返回通用 503。

数据集、报表与刷新 ​

  • 可选 Strawberry Django 模型注册、字段目录、分页明细、按 ID 查询、类型化筛选、多字段排序和聚合。
  • COUNT/SUM/AVG/MIN/MAX、去重计数、最多 3 维分组、时间粒度与时区，以及查询/扫描预算。
  • 可编辑数据集草稿、修订冲突、不可变发布版本、参数、预览、差异比较、归档/恢复及依赖关系。
  • 大屏/H5 组件选择固定版本、字段映射与类型化实参；业务结果仅用于渲染，不写入页面配置。
  • 明确声明的 JSON 标量子字段、单值关联与持续时间字段；精确整数/小数保留文本表示，并说明数据库精度边界。
  • 自助报表、大数字、图表和表格；工作台/大屏/H5 嵌入、1–20 张卡片的报表看板、按当前权限生成的私有定时导出。
  • 组件和报表独立选择手动、定时、通知或组合刷新；隐藏时暂停，权限变化清除结果，取消与迟到响应隔离。
  • 可选 Channels/Redis 模型失效通知，独立只读服务身份与受限 GraphQL/固定版本数据访问。

权限、安全与协作 ​

  • 复用模型/模块、QuerySet、对象、字段、软删除和租户权限；筛选不会扩大授权范围。
  • 个人资源按创建者管理；可选协作工作区、账号/用户组角色、逐资源授权、宿主组织目录与所有权交接。
  • 公开业务取数通过按页只读授权，只返回已确认绑定与映射字段；不开放匿名模型订阅。
  • Session/CSRF、登录验证码、失败锁定、TOTP、一次性恢复码、IP/CIDR 范围及可选会话设备管理。
  • 按接收人隔离的站内通知、按范围读取的操作日志和默认预览的分批审计留存。
  • 模型 Webhook 队列、签名、退避、租约、当前权限复核，以及服务端凭据管理的钉钉/飞书机器人适配。

离线与运维 ​

  • PWA 程序准备、断网画布编辑、JSON 导入导出及联网另存；额外启用的只读业务快照支持本机查看与文件管理。
  • 只读配置诊断、初始化配方、迁移计划与引用索引检查；写入类维护命令默认预览，显式 --apply 执行。
  • 默认关闭的后台任务运行诊断：超级管理员只读查看五类任务的有限历史、耗时、安全计数和队列积压。
  • 任务调度由宿主负责；多进程使用同一默认共享缓存。诊断不提供网页执行入口，不保存参数、业务结果或原始异常。

验证与使用边界 ​

  • 完整后端检查覆盖权限、查询、页面、报表、表单、安全、协作和任务；另有 PostgreSQL、Redis 跨进程及真实浏览器检查。
  • 新库安装确认模块、表、ContentType、迁移记录与有效权限前缀均为 ordloom。
  • 生产任务调度、组织策略映射、长期大屏运行、真机安装及外部机器人群接收需按目标部署验证。
  • 离线副本使用导出文件语义；缓存历史不代替持久审计或实时进程心跳。在线自定义代码/云函数不属于本版能力。

完整配置见 Django 手册，当前能力与后续计划见 ROADMAP。
