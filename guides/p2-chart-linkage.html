多序列图表与组件联动 ​

本指南描述 Ordloom 1.1.0 的多序列与参数联动能力。

多指标与分组序列 ​

页面组件的柱图、条形图、折线图和面积图，在原有「类目 + 主要指标」映射之外，可增加最多 7 个附加指标以及一个分组序列字段。业务报表构建器提供同样的选择；报表继续支持工作台、大屏/H5 嵌入及报表看板。

例如按月份和区域分组，选择金额与订单数两个指标：横轴为月份，分组字段为区域，每个区域分别生成金额、订单数两个序列。不同单位的指标应拆分组件，本批次没有自动单位换算或双轴。

  • 保留查询返回顺序，最多显示 32 个序列，图例可滚动。
  • 缺少某个「类目 + 分组」组合时显示空档；不会自动补零或重新求和。
  • 同一个组合返回多行时明确报错，先在数据集中完成聚合。指标为空、非数值、溢出或不安全整数时继续拒绝绘图，可改用文本、指标或表格保留精确原值。
  • 原有单序列映射及静态示例保持原行为。饼图、仪表盘等图形仍使用原单值协议。
  • 公开授权仍按映射裁剪数据，包括附加指标和分组字段；不会额外返回未映射字段。离线业务快照保留相同映射和数值校验。

数据集映射例子：

json
{
  "category": "dimensions.month",
  "value": "metrics.amount",
  "values": ["metrics.count"],
  "series": "dimensions.region"
}

点击筛选、重置与明细钻取 ​

打开「组件数据绑定」或「业务报表组件配置」，展开「点击联动与明细钻取」。配置不执行任意查询代码：只把一个原始标量值传给目标查询已经声明的参数。

  1. 在源 ECharts 分类图表（雷达、仪表盘除外）或源表格上启用联动，填写通道名，如 selected_state，选择点击输出字段，如 dimensions.state。
  2. 在目标组件上使用相同通道名，选择其查询已经声明的接收参数，如 state。参数必须已在查询筛选中使用；组件原实参作为重置基线。
  3. 预览或打开后台页面，点击源图形或表格行。目标组件重新执行，沿用当前登录账号的模型、字段、对象、租户与工作区权限。
  4. 目标使用明细数据集的表格组件，或按明细维度配置的表格报表，即可展开对应明细。点击「重置联动筛选」恢复组件保存的实参。

同一协议用于工作台报表卡片、后台数字大屏/H5 的数据集或报表组件、报表看板。联动通道仅在当前页面会话内传播，不写回页面或报表，不进入共享缓存，不在页面之间传播，轮播换页重置。多个组件可以接收同一通道；一个组件也可同时作为发送方与接收方。

只有标量参数可接收联动，数组参数不适用。字符串（包括精确 Decimal/BigInt）、布尔、有限安全数值与空值保持原类型；不根据展示标签转换成筛选代码。原查询类型不匹配时服务端拒绝，原权限规则仍然优先。

源组件配置：

json
{"channel": "selected_state", "field": "dimensions.state"}

目标配置：

json
{"channel": "selected_state", "parameter": "state"}

页面数据集使用可选 dataBinding.interaction；报表引用使用可选 reportInteraction。服务端保存时校验字段属于当前发布版本/报表输出，接收参数属于当前查询声明，不开放任意字段路径或附加筛选表达式。查询定义变化后仍按现行查询与权限校验，联动不会冻结或恢复历史权限。

公开分享与离线边界 ​

公开链接只执行创建者批准的固定版本、固定参数与映射；公开组件不接收联动，也不会因为点击而修改取数参数。后台配置界面有明确说明。公开展示仍可使用多序列图表。后续若支持公开交互，需要独立设计明确的可变参数授权范围，本批次没有放宽公开授权。

页面发布快照固定组件配置与查询引用；数据集始终引用指定发布版本，嵌入报表仍使用报表当前定义。历史页面回滚不会把报表定义或业务权限一并回滚。

离线业务快照显示捕获时已授权的数据，不提供联动授权查询或后台明细钻取。

验证入口 ​

  • 前端模型：node --test frontend/tests/multi-series-linkage.test.js。
  • React/DOM：node frontend/tests/run-chart-linkage-ui.mjs；覆盖筛选、重置、换页、公开固定参数、工作台与报表上下文、ECharts 点击坐标到原始字段值的映射。DOM 检查不等于实际 Canvas 绘制验收。
  • Django：python scripts/test_backend.py ordloom.tests.test_chart_linkage；同时保留原页面绑定、报表、看板、公开授权与离线快照回归。
